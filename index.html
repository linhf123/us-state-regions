分区说明

  • 美西：太平洋沿岸 + 山地西侧，含 AK / HI。
  • 美中：五大湖 + 中西部平原，含 KY。
  • 美南：墨西哥湾沿岸 + 德州 + 田纳西。
  • 美东：东北 + 东南沿海，含 DC。
  • TX / OK / AR / LA / MS / AL / TN 划入美南；KY 仍归美中，NH 仍归美东。
  • 不设「美北」：北部各州与中西部高度重合，单列后与美中难以区分。
